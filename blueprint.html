Source-first product plan

Blueprint for a trusted Vedic learning companion.

VedaPath AI should help users move from curiosity to understanding through source-cited answers, careful categories, progressive depth, and reviewed correction loops.

Open Prototype Raw Markdown
Positioning

What It Is

  • A study assistant for Vedic and Hindu philosophical texts.
  • A citation-first scripture explorer.
  • A Sanskrit and concept explainer.
  • A bridge between modern questions and traditional sources.
Guardrails

What It Is Not

  • Not a digital guru, oracle, fortune teller, or ritual authority.
  • Not a replacement for teachers, priests, scholars, or tradition.
  • Not a tool for inflated claims like "the Vedas prove all modern science."

Source Labels

VedaPath can cover a broad Hindu wisdom landscape, but every answer must label where it is standing.

Signature Features

Pramana Meter

Labels whether an answer is direct source, commentary, scholarly view, analogy, or speculation.

Mantra Lens

Future verse-level view with Sanskrit, transliteration, word meanings, meter, and recitation context.

Claim Checker

Separates what the source says from tradition, modern claims, and overextended interpretations.

Samvada Mode

Compares interpretations respectfully without pretending every school says the same thing.

Learning Path

Adapts to beginners, Sanskrit learners, philosophy readers, and teachers.

Calm Path

Guides source-backed reflection for personal steadiness without becoming therapy, ritual advice, or a guru voice.

Daily Calm Loop

Saves a private browser-only reflection pattern so users can learn from their own source-backed practice.

Source Practice

Turns calm into a timed source-backed workflow with arrival, reading, reflection, and carry action.

Source Library

Organizes curated source candidates with filters, shelf memory, and practice handoff.

Source Seeds

Turns prototype citations into structured seed records with review gates, missing fields, and copyable schema handoff.

Retrieval Lab

Searches source seeds, shows the source stack and match reason, and refuses unsupported proof claims.

Passage Review Pack

Shows meaning capsules, allowed use, missing production fields, review decisions, and evaluation checks before answer authority.

Evaluation Runner

Checks draft answers for citation gaps, source-family confusion, unsafe calm advice, ritual authority, and overclaiming.

Evaluation Dashboard

Turns answer checks into a visible release gate with blocked examples, issue counts, and reviewer export.

Reviewer Queue

Turns failed checks, flagged passages, retrieval gaps, and correction notes into human-review cards.

Source Policy Console

Shows whether a question should be answered, bounded, reviewed, or deferred before confidence appears.

Trust Ledger

Turns policy routes and review outcomes into versioned governance records with copyable handoff.

Life Map

Routes real-life pressure to one source candidate, one boundary, one action, and the next useful room.

Calm Circle

Routes shared pressure to one source, one shared question, one boundary, and one small agreement.

Source Path Builder

Turns source candidates into a small personal learning route with local progress and practice handoff.

Calm Compass

Routes a present state to one source-backed action and the best next room without hidden profiling.

Calm Card Studio

Turns a source-backed reflection into a shareable card while preserving citation and boundary.

Source Bell

Turns one source-backed reflection into a one-minute visual pulse with a soft bell and carry action.

Before Reply

Helps users pause, source, and draft a calmer response before a reactive message is sent.

Samvada Room

Maps two views fairly and turns disagreement into a source-backed shared question.

Sankalpa Studio

Turns personal calm into one private 24-hour intention with source, boundary, and carry action.

Seva Planner

Turns steadiness into one small helpful act while preserving capacity, boundary, and source context.

Morning Path

Helps users begin the day with one source candidate, one honest line, and one clean first action.

Evening Reflection

Helps users close the day with acknowledgement, release, source context, and no self-judgment.

Calm Rhythm

Reads browser-local VedaPath traces and suggests one next room without accounts, sync, or hidden profiling.

Correction Loop

User suggestions become reviewed annotations, not silent knowledge-base rewrites.
