# Source Bell

Source Bell is a one-minute source-backed reset for everyday steadiness.

It is designed for moments when a user does not need another long explanation. They need to arrive, look at one source candidate, and carry one action.

## Product Shape

- Pick a present state.
- Start a 60-second visual pulse.
- Hear an optional soft browser-generated bell.
- See one source candidate, text family, question, and boundary.
- Complete the bell and store a device-local rhythm.
- Copy a short handoff for personal use or Calm Card Studio.

## Boundary

Source Bell is reflection support. It is not therapy, medical advice, emergency support, ritual instruction, or a replacement for teachers, family, clinicians, or tradition.

## Why It Matters

This gives VedaPath a practical daily use case without abandoning the source-first promise. The source, category, question, action, and boundary stay visible even in a tiny calm moment.

## Before Reply Bridge

Source Bell can precede Before Reply when a user needs a quiet minute before drafting a message. The reply tool should preserve the bell's source frame and boundary instead of turning the pause into relationship advice.
