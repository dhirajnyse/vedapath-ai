# VedaPath AI UX Principles

UI/UX simplicity is a core product advantage, not decoration.

Every phase and release should be judged by this question:

Can a curious user understand what to do next in less than five seconds?

## UX Doctrine

### 1. Source First, Screen Simple

The answer should be easy to read first. Citations, Sanskrit layers, and commentary should be available without overwhelming the first view.

Default answer layout:

- Direct answer
- Source card
- Plain explanation
- Expandable deeper layers

### 2. Progressive Depth

Do not show everything at once.

Use layers:

- Simple
- Source
- Sanskrit
- Commentary
- Debate
- Scholar notes

### 3. No Decorative Confusion

Bhagwa, Sanskrit motifs, and 3D identity should create warmth and trust, not visual noise.

Avoid:

- too many ornaments
- heavy religious decoration in every panel
- complex backgrounds behind reading text
- glowing UI everywhere
- landing-page drama inside the actual product

### 4. Reading Is Sacred Work

Text must be comfortable.

Rules:

- generous line height
- high contrast
- no tiny Sanskrit
- no long walls of text in the first answer
- citations must be visible but quiet
- mobile reading must be excellent

### 5. One Primary Action Per Screen

Each main screen should have one obvious next action.

Examples:

- Ask a question
- Open source
- Compare interpretations
- Continue learning path
- Suggest correction

### 6. Trust Is A UI Element

Trust should be visible through design:

- source labels
- confidence meter
- "what not to overclaim"
- correction history
- reviewer status

### 7. The Product Should Not Feel Like A Chatbot Only

Chat is one doorway, not the whole building.

Core surfaces:

- Ask
- Explore
- Learn
- Check a Claim
- Read a Text
- Review Notes

## First Screen Recommendation

The first screen should be a functional search/chat workspace, not a marketing landing page.

Suggested layout:

- Top: VedaPath AI identity and simple navigation
- Center: one large question input
- Below: suggested question chips
- Right or below: learning path card
- Footer area: source-first promise

## Simplicity Standards For Every Release

Before shipping, check:

- Can a new user ask a question immediately?
- Does the first answer fit without feeling crowded?
- Are source labels clear?
- Are advanced layers hidden until requested?
- Does Bhagwa support the interface instead of dominating it?
- Does mobile feel first-class?
- Is every visual element helping comprehension?
