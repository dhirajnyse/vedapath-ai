# Trust Model

Trust Model is the v0.5.0 bridge from VedaPath AI prototype rooms to a production-ready data architecture.

It turns the current trust surfaces into a visible backend contract before the product adds real accounts, durable memory, or retrieval authority.

## Why It Exists

VedaPath is becoming a personal calm and source-first learning product.

That means the product must not simply remember more. It must remember with restraint.

The Trust Model gives the product one rule:

No personal calm pattern, source record, user correction, or shared-circle note becomes durable memory until it has purpose, consent, source trace, deletion path, review route, and audit visibility.

## Current Prototype

The v0.5.0 Trust Model includes:

- six production entities:
  - Memory Route
  - Consent Grant
  - Source Seed
  - Review Decision
  - Trust Event
  - Calm Pattern
- a source-to-memory flow map
- launch readiness score per entity
- required field cards
- backend table preview
- copyable model brief
- copyable JSON schema preview

## Product Role

Trust Model makes the future backend understandable before it exists.

It should:

- show how Source Seeds, Consent Gate, Memory Gate, Reviewer Queue, and Trust Ledger connect
- keep user-owned calm patterns separate from inferred profiling
- make review and audit mandatory before accepted knowledge changes
- preserve export, deletion, and withdrawal paths as first-class product controls
- prevent durable memory from becoming silent data capture

## Core Entities

### source_seed

Reviewed source candidates, citations, families, translation policy, rights, and answer boundaries.

### consent_grant

Purpose, scope, participant consent, withdrawal path, export path, and deletion path.

### memory_route

Local, review, ledger, or blocked verdict before recall or durable reuse.

### review_decision

Reviewer identity, evidence path, decision, source impact, safety flags, and version impact.

### trust_event

Versioned governance event tied to answer behavior, source status, policy route, review, and audit history.

### calm_pattern

User-owned reflection pattern with minimal deliberate fields, source context, export path, and delete path.

## What It Is Not

Trust Model is not:

- a production database
- legal or compliance certification
- a privacy policy
- a reason to collect more personal data
- an automated authority system
- hidden profiling
- a replacement for reviewed source, consent, and safety work
