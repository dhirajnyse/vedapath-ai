# Seva Planner

Seva Planner turns personal calm into one small source-backed helpful act.

It helps a user:

- choose where help is needed
- name today's real capacity
- keep one source candidate visible
- choose a quiet, skilled, or bounded act
- save the plan only in the current browser during the prototype

## Product Boundary

Seva Planner is reflection support. It is not moral ranking, therapy, emergency support, legal advice, ritual instruction, or a command to overextend yourself.

Seva should not become guilt. The product should help calm move into useful action while preserving rest, safety, agency, and source context.

## Prototype Sources

- Bhagavad Gita 3.19 for action without attachment.
- Bhagavad Gita 2.47 for effort without outcome-control.
- Bhagavad Gita 12.13 for compassion with steadiness.
- Katha Upanishad 1.3.3-9 for stewarding attention.

## Why This Matters

VedaPath should not only help users feel better privately. It should help calm become a small good in the world, without inflating the app into a judge or spiritual authority.
