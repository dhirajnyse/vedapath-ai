# Calm Card Studio

## Purpose

Calm Card Studio turns one source-backed reflection into a simple visual card. It is a launch-friendly artifact that helps users carry one grounded action without losing the source, text family, or boundary.

## What It Proves

- VedaPath can create a memorable brand object without becoming a guru voice.
- A single source-backed action can be copied, saved locally, or exported as an image.
- Sharing can preserve citation and caution instead of stripping them away.
- Browser-local memory can test card habits before accounts or publishing tools exist.

## Prototype Behavior

The page stores saved cards in browser localStorage under `vedapath.calmCards.v1`.

Each card includes:

- Present state
- Source candidate
- Text family
- Reflection question
- Personal action
- Optional user label
- Visible boundary

The PNG export is generated in the browser from the current card preview. It does not upload the card anywhere.

## Boundary

Calm Cards are personal reflections. They are not therapy, medical advice, emergency support, ritual instruction, diagnosis, or universal advice for other people.
