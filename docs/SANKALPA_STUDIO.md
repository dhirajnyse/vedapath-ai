# Sankalpa Studio

Sankalpa Studio is a private, source-backed intention builder for the next 24 hours.

It helps a user:

- choose today's inner need
- name the pressure honestly
- see one source candidate and source family
- generate one small intention
- carry one grounded action
- save the intention only in the current browser during the prototype

## Product Boundary

Sankalpa Studio is reflection support. It is not ritual instruction, therapy, medical advice, emergency support, or a command from the app.

The word Sankalpa can carry ritual and philosophical depth in different traditions. VedaPath should use it carefully: as a user-owned intention, not as an app-issued vow or spiritual prescription.

## Prototype Sources

- Bhagavad Gita 2.48 for steadiness.
- Mundaka Upanishad 1.1.4-5 for clarity.
- Bhagavad Gita 2.47 for courage.
- Bhagavad Gita 12.13 for kindness.

## Why This Matters

VedaPath should help calm become concrete without pretending to control a user's life. The studio turns source-backed reflection into one small 24-hour practice with visible boundaries.
