# VedaPath AI UX Flow Reset

This is the v2.8.5 UX Flow Reset release.

## Problem

The product had grown through many release rooms. The home page started to feel scattered because every new room appeared with similar visual weight.

## Change

- Rebuilt the home page around one guided product flow: Ask, Source, Practice, Pattern.
- Kept the Ask surface in the first product area.
- Reduced the right rail to one next-lane decision, MVP progress, and correction loop.
- Added a grouped room map for deeper exploration.
- Refined the shared sprint CSS so room pages have calmer sizing, shorter columns, and contained room lists.

## Boundary

This is a UX organization build. It does not change source claims, retrieval data, privacy rules, or spiritual boundaries.
