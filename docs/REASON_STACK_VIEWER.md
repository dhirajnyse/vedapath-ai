# VedaPath Reason Stack Viewer

This is the v2.2.7 VedaPath Reason Stack Viewer release for VedaPath AI.

## Purpose

Reason Stack Viewer builds trust by making retrieval evidence visible.

## Retrieval Focus

- Sample query: How do I tell short term comfort from a deeper good?
- Intent lane: discernment
- Boundary: Reason stack preview, not evaluation proof.

## Retrieval Signals

- Query path: User language is matched to curated source records. Keeps answers source-led.
- Reason path: Ranking reasons and readiness stay visible. Makes retrieval inspectable.
- Boundary path: No-go language travels with each candidate. Prevents overclaim.
- Trace path: The chosen source can be copied as a trace packet. Supports review.
