# Command Shell Font Rhythm Refinement

Release: v3.3.8

## Purpose

VedaPath already has the right shell direction. This release makes the typography feel more cohesive, mature, and calm across the command center, source rooms, practice rooms, and build surfaces.

## What Changed

- Reduced the top display scale so heroes feel strong without overwhelming the workspace.
- Added a dedicated answer-title tier for important answer headings.
- Lowered excess font weight in rail labels, metrics, badges, controls, and card headings.
- Tuned body, lead, card, and supporting copy into a tighter reading rhythm.
- Preserved fixed type sizes and zero letter spacing for calm readability.

## Product Rule

Every future build should add capability without breaking the rhythm: one command shell, one clear hierarchy, and no page-specific typography drift unless the task truly requires it.

## Boundary

This is a visual-system refinement. It does not change source policy, answers, storage, authentication, or review behavior.
