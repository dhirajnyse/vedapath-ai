# VedaPath Reader Memory Preview

This is the v2.0.1 VedaPath Reader Memory Preview release for VedaPath AI.

## Purpose

Reader Memory Preview lets VedaPath test habit loops without pretending to have durable user accounts.

## Source Candidate

- Source: Bhagavad Gita 2.48
- Text family: Bhagavad Gita | Smriti
- Boundary: Local memory preview, not account history.

## Reader Signals

- Local save: Reading sessions stay in this browser only. Protects privacy.
- Streak preview: Session count and last passage are visible. Tests habit value.
- Clear control: The user can clear preview memory. Keeps control local.
- No profile claim: The app does not infer identity or spirituality. Avoids hidden profiling.

## Founder Action

Test reading rhythm with browser-only memory and a clear privacy boundary.
