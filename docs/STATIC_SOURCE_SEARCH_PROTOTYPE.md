# VedaPath Static Source Search Prototype

This is the v1.8.0 VedaPath Static Source Search Prototype release for VedaPath AI.

## Purpose

Static Source Search Prototype gives VedaPath a visible bridge from curated seed data to source-first answer retrieval.

## Source Candidate

- Source: Isha Upanishad 1
- Text family: Upanishad | Shruti
- Boundary: Static search prototype, not live semantic retrieval.

## Beta Data Signals

- Filter fields: Topic, family, intent, review state, and risk tag. Makes search transparent.
- Result reason: Explain why a record matched the question. Builds confidence.
- Hold display: Held records can explain why they are not eligible. Shows discipline.
- No-result state: A no-source fallback appears before any answer is composed. Prevents guessing.

## Founder Action

Prove that the first beta can find candidate records without guessing.

## No-Go Boundary
