# VedaPath AI MVP Roadmap

Goal:

Define product identity, trust principles, brand, and repo structure.

Deliverables:

- product blueprint
- UX principles
- brand system
- sample questions
- source policy
- GitHub repo

## Phase 2: Retrieval Prototype

Goal:

Connect a small curated source set.

Status:

Active product phase. Source Seeds now shows the first structured source schema and prototype seed records. Retrieval Lab now shows the first source-stack ranking, match reason, boundary, and no-source claim refusal. Passage Review Pack now shows passage dossiers, allowed use, missing production fields, local review decisions, and evaluation checks. Evaluation Runner now checks answer drafts before user-facing trust.

Initial data:

- 25 to 50 hand-curated questions
- selected Vedic and Upanishadic passages
- Bhagavad Gita references for common cultural questions
- glossary for core terms
- source seed records with review gates and missing production fields
- passage dossiers with allowed use, answer boundary, review decision, and evaluation checks

Features:

- semantic search
- cited answers
- source classification
- confidence labels
- retrieval trace
- no-source refusal for unsupported claims
- passage review gate before answer authority
- answer draft evaluation for citation gaps, source-family confusion, unsafe calm advice, ritual authority, and overclaiming

Success criteria:

- 100 test questions answered with citations or honest uncertainty.
- No answer should silently mix Veda, Gita, Purana, and modern interpretation.

## Phase 3: Learning Loop

Goal:

Let the product improve from usage without blindly learning from users.

Features:

- saved learning profile
- question heatmap
- correction suggestions
- reviewer queue
- accepted annotation history

Success criteria:

- User feedback improves content quality after review.
- Private user chats are not used as raw training data.

## Phase 4: Sanskrit And Voice

Goal:

Add deeper Sanskrit and chanting support.

Features:

- sandhi split experiments
- word-by-word views
- audio playback
- chant practice prototype
- pronunciation feedback research

Success criteria:

- Sanskrit layer helps beginners without pretending to replace experts.

## Phase 5: Scholar Network

Goal:

Build credibility through human review.

Features:

- verified contributor profiles
- reviewer dashboard
- interpretation notes
- disagreement labels
- source versioning

Success criteria:

- Scholars and teachers can trust how the app handles nuance.
