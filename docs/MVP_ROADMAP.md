## Phase 2: Retrieval Prototype

Goal:

Connect a small curated source set.

Status:

Active product phase. Source Seeds now shows the first structured source schema and prototype seed records. Retrieval Lab now shows the first source-stack ranking, match reason, boundary, and no-source claim refusal. Passage Review Pack now shows passage dossiers, allowed use, missing production fields, local review decisions, and evaluation checks. Evaluation Runner now checks answer drafts before user-facing trust. Evaluation Dashboard now tests the evaluator as a visible release gate. Reviewer Queue now turns failed examples, flagged passages, retrieval gaps, and correction notes into local human-review cards. Source Policy Console now makes answer gates visible before the AI speaks with confidence. Trust Ledger now turns policy routes and queue decisions into versioned local governance records before accepted behavior changes. Life Map now routes real-life moments to one source candidate, one boundary, and one next action without overstepping into advice.

Initial data:

- 25 to 50 hand-curated questions
- selected Vedic and Upanishadic passages
- Bhagavad Gita references for common cultural questions
- glossary for core terms
- source seed records with review gates and missing production fields
- passage dossiers with allowed use, answer boundary, review decision, and evaluation checks

Features:

- semantic search
- cited answers
- source classification
- confidence labels
- retrieval trace
- no-source refusal for unsupported claims
- passage review gate before answer authority
- answer draft evaluation for citation gaps, source-family confusion, unsafe calm advice, ritual authority, and overclaiming
- evaluation dashboard for expected behavior checks, blocked examples, issue counts, and reviewer export
- reviewer queue for failed examples, flagged passages, retrieval gaps, and user correction notes
- source policy console for answer allowed, boundary required, review route, and decline/defer decisions
- trust ledger for source-policy routes, reviewer needs, decision history, and governance handoff
- life map for real-life moment routing with source, boundary, local pattern preview, and consent boundary

Success criteria:

- 100 test questions answered with citations or honest uncertainty.
- No answer should silently mix Veda, Gita, Purana, and modern interpretation.

## Phase 3: Learning Loop

Goal:

Let the product improve from usage without blindly learning from users.

Features:

- saved learning profile
- question heatmap
- correction suggestions
- reviewer queue
- accepted annotation history

Success criteria:

- User feedback improves content quality after review.
- Private user chats are not used as raw training data.

## Phase 4: Sanskrit And Voice

Goal:

Add deeper Sanskrit and chanting support.

Features:

- sandhi split experiments
- word-by-word views
- audio playback
- chant practice prototype
- pronunciation feedback research

Success criteria:

- Sanskrit layer helps beginners without pretending to replace experts.

## Phase 5: Scholar Network

Goal:

Build credibility through human review.

Features:

- verified contributor profiles
- reviewer dashboard
- interpretation notes
- disagreement labels
- source versioning

Success criteria:

- Scholars and teachers can trust how the app handles nuance.
