# v4.8.0 Integrated Ask Demo

## Purpose

The first integrated Ask demo works immediately from the reviewed static registry and can optionally connect to the private local Source API.

## What Changed

Adds an accessible learner-facing Ask workspace with sample questions, reviewed-preview and local-API modes, source cards, no-source states, visible boundaries, and no storage or telemetry.

## Acceptance Checks

Per-version page, data, document, syntax, API contract, registry, static-link, HTTP smoke, and browser visual checks.

## Known Risks

Private-demo and reviewed-preview only; no live AI generation, production corpus delivery, durable accounts, hidden telemetry, payments, public launch, or medical, legal, ritual, or spiritual authority.
