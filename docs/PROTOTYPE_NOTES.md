# v0.2.7 Prototype Notes

The v0.2.7 release turns the VedaPath AI homepage into a clickable product prototype with calm, practice, source-library, source-path, calm-compass, and calm-card surfaces.

## Included

- Ask workspace
- Curated sample question chips
- Source Card
- Pramana Meter
- Layer tabs for source, Sanskrit, interpretations, and claim checking
- Claim Checker panel
- Learning Path rail
- Calm Path
- Daily Calm Loop
- Source Practice timer and local rhythm
- Source Library with search, filters, shelf, and practice handoff
- Source Path Builder with intention, local progress, source mix, and practice handoff
- Calm Compass with present-state routing, local signal, and practice handoff
- Calm Card Studio with visual preview, local saved cards, copy text, and PNG export
- Correction Loop placeholder
- MVP progress update

## Prototype Boundary

The current app does not call a live LLM or retrieval backend. It uses a small curated in-page sample dataset so the first experience can test product shape, trust language, and UX simplicity before backend work begins.

## Why This Matters

This release proves the product direction:

- first screen is usable, not a marketing page
- answers show source classification
- users can see confidence and caution
- deeper layers stay hidden until requested
- source candidates can become a small personal route
- one current-life state can route to the next useful product room
- one source-backed action can become a shareable visual artifact
- the UI remains calm and Bhagwa-led without becoming visually loud

## Next Release

v0.3.0 should turn the prototype library and path data into a structured source schema and the first 25 to 50 verified answer records.
