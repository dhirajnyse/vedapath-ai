# VedaPath AI Cohesive UI System

This is the v2.8.6 UI cohesion pass.

## Problem

The product had strong individual rooms, but the experience still felt scattered because different page families used different header structures, title scales, logo sizes, and navigation treatments.

## Changes

- Added a shared visual cohesion layer at `assets/vedapath-cohesive.css`.
- Restored the full top navigation on the Build Status page.
- Normalized page width, header spacing, nav behavior, active states, version badge, title scale, panel radius, and logo/image treatment.
- Tightened sprint-room sidebars and hero areas so the rooms feel like siblings.
- Replaced internal home-page release language with product-facing copy.

## Boundary

This is a UI/UX cohesion release. It does not change source claims, retrieval data, Sanskrit handling, or safety boundaries.
