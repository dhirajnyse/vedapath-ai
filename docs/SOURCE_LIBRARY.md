# Source Library

## Purpose

Source Library is the first visible knowledge layer for VedaPath AI. It organizes prototype source candidates so users can search, filter, save a device-local shelf, send a selected source into Source Practice, feed Source Path Builder, and support Calm Compass routing.

## What It Proves

- The product can start with source discovery instead of answer generation.
- Calm, practice, claim checking, mantra study, and learning can share one source-card model.
- Users can build a personal source shelf without hidden tracking.
- A selected source can hand off into Practice while keeping citation and category visible.
- The same records can become ordered path steps without losing source boundaries.
- The same records can help Calm Compass route an explicit present state to one next action.

## Current Record Shape

Each prototype record includes:

- Title
- Citation
- Text family
- Use tags
- Status
- Summary
- Reflection question
- Carry action
- Boundary
- Practice state hint
- Compass state hint

The current records are prototype candidates, not production source data.

## Future Production Requirements

- Verified Sanskrit text where relevant
- Translation policy and licensing
- Source edition metadata
- Reviewer notes
- Category and confidence fields
- Search fields and retrieval ids
- Path intent and recommended-order fields
- Export and delete controls for user shelf data

## Guardrail

The library must not pretend to be canonical until records are reviewed. It should say when a source is a candidate, when a claim is uncertain, and when an interpretation belongs to a specific tradition.
