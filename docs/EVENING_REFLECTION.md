# Evening Reflection

Evening Reflection is the closing doorway for VedaPath AI.

It helps a user end the day with:

- one honest evening state
- one source candidate
- one acknowledgement
- one release
- one clean close
- a device-local seven-day closing pattern

## Product Role

Evening Reflection is not a sleep app, therapy tool, ritual authority, or productivity review.

It is a calm close layer. The user should be able to put the day down without making the day into a verdict on the self.

## Source Candidates

Prototype candidates:

- Tired: Bhagavad Gita 6.17
- Tangled: Bhagavad Gita 6.26
- Grateful: Taittiriya Upanishad 1.11
- Regretful: Bhagavad Gita 2.47

Each candidate needs reviewed text, translation handling, source family, and caution before becoming production knowledge.

## Boundary

Evening Reflection is reflection support. It is not therapy, medical advice, emergency support, sleep treatment, ritual instruction, astrology, or a replacement for teachers, family, clinicians, or tradition.

The feature should reduce rumination, not deepen it.

## Why It Matters

Morning Path helps a user begin. Evening Reflection helps the user close.

Together they create a simple daily rhythm: start with source, live with care, close with humility, and return tomorrow without shame.

Calm Rhythm can read the evening close as one local signal, but it must never treat a missed close as failure. The pattern exists to suggest a next room, not judge the day.
