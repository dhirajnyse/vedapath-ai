# Morning Path

Morning Path is the first-start doorway for VedaPath AI.

It helps a user begin the day with:

- one honest state
- one source candidate
- one line from the morning
- one clean first action
- one visible boundary
- a device-local seven-day opening pattern

## Product Role

Morning Path is not a productivity app and not a ritual authority. It is a calm start layer that makes the source visible before the day becomes noisy.

The page should feel like opening a quiet desk, not entering a dashboard.

## Source Candidates

Prototype candidates:

- Restless: Bhagavad Gita 2.48
- Heavy: Katha Upanishad 1.3.14
- Scattered: Bhagavad Gita 6.26
- Steady: Bhagavad Gita 3.19

Each candidate needs reviewed text, translation handling, source family, and caution before becoming production knowledge.

## Boundary

Morning Path is reflection support. It is not therapy, medical advice, emergency support, ritual instruction, astrology, or a replacement for teachers, family, clinicians, or tradition.

The feature should help users begin without making the morning a moral score.

## Why It Matters

Most calm products ask users to pause. Morning Path also asks them to begin.

That makes the product more useful: VedaPath can support steadiness, learning, service, and daily action while keeping citation and humility visible.

## Companion Feature

Evening Reflection should close the same loop at night: acknowledge, release, and preserve one source-backed boundary before rest.
