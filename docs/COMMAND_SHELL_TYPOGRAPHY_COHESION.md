# Command Shell Typography Cohesion

Release: v3.3.7

Command Shell Typography Cohesion tightens the shared VedaPath type system after the immersive visual polish pass. The goal is not to make the interface louder. The goal is to make every room feel designed from one calm hand.

## What Changed

- Reduced hero and room title sizes so practical work surfaces do not feel oversized.
- Protected side-rail group labels such as Start, Source, and Practice from global h2 styling.
- Unified card titles, step labels, route labels, metrics, buttons, inputs, and body copy.
- Kept fixed font sizes with breakpoint overrides instead of viewport-width scaling.
- Preserved the Bhagwa, peacock green, sacred gold, indigo, and ivory system from the previous polish releases.

## Typography Contract

- Shell title: 23px
- Hero title: 38px
- Room title: 31px
- Section title: 19px
- Card title: 15.5px
- Body: 14.75px
- Lead text: 15.75px
- Controls: 13.5px
- Small labels: 10.5px
- Metrics: 23px

## Product Rule

VedaPath should feel like a calm command center, not a poster. The logo, source cards, rail, and color atmosphere can carry the sense of world-building while repeated product surfaces stay readable and disciplined.
